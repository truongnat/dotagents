# Script hỗ trợ

- `search-memory.sh` — tìm memory theo từ khóa, ưu tiên corpus active.
- `validate-skills.sh` — kiểm tra cơ bản frontmatter, kebab-case và sự khớp giữa `name` với tên thư mục.

Chạy từ root repository: `bash .agents/scripts/validate-skills.sh`. Đây là validator nhẹ, không thay thế validator chính thức của Agent Skills specification.
